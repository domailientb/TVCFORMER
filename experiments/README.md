# Thực nghiệm TVCFormer

Thư mục này chứa các mã nguồn và tài liệu phục vụ cho quá trình tái thực nghiệm và phân tích mô hình TVCFormer.

## Thực nghiệm hiện tại

Thực nghiệm đầu tiên sử dụng bộ dữ liệu ETTh1.

- Mô hình: TVCFormer
- Bộ dữ liệu: ETTh1
- Độ dài chuỗi đầu vào: 336
- Độ dài dự báo: 192
- Batch size: 128
- Số epoch tối đa: 100
- Thiết bị: CPU

File chạy tái thực nghiệm:

`reproduce_tvcformer.py`

Kết quả thực nghiệm cuối cùng sẽ được bổ sung sau khi quá trình huấn luyện hoàn tất.
