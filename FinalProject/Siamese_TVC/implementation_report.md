# Siamese_TVC implementation handoff

## Method and rationale

The implementation uses a shared local-window encoder: per-window scale-aware descriptors and TVC statistics enter an MLP projection, while a Conv1D branch receives the normalized local window. The CNN focuses on temporal shape; level and scale remain explicitly represented in the descriptors/statistics. Embeddings are L2-normalized before cosine comparison.

Candidate selection now has Pearson, Siamese and hybrid modes. E1 ranks all unordered channel pairs by aligned-window Siamese cosine. E2 forms the union of Pearson and Siamese Top-K, then uses Borda rank fusion to select the baseline Top-K budget. This retains equal support size across E0/E1/E2 and avoids adding Pearson values and cosine values on incomparable numeric scales. The selected support is mirrored to create undirected edges. Configured self-loop policy is preserved. A sample's local input context alone determines candidates; no target or future values are passed to the graph builder.

The five dataset configurations match `FinalProject/Clustering_TVC/configs`: four ETT datasets have 7 channels and Weather has 21. Shared training/model parameters are centralized; dataset YAMLs contain only dataset-specific metadata; E0/E1/E2 overlays contain only experimental differences. No test-split-derived tuning or dataset-specific graph hyperparameters were introduced. Train-only descriptive statistics can be generated by `analyze_datasets.py` before proposing later changes.

## Experimental definitions

- **E0:** official TVCFormer model and Pearson graph, with the same validation-only training/checkpoint protocol.
- **E1:** Siamese-only candidate support and fixed Siamese edge similarity.
- **E2:** union candidate support and learned sigmoid gate combining statistical and learned edge similarity.

All reuse the official data split/scaling, input length 336, optimizer/lr, batch, maximum epochs/patience and metrics by default. Test runs once after selecting a checkpoint by validation. Benchmark defaults are the five fixed datasets, horizons 96/192/336/720 and seeds 2021/2023/2025.

## Added/updated components

- `models/similarity.py`: normalized-window temporal CNN, shared projection, similarity, candidate selector and rank fusion.
- `models/graph_generator.py`: candidate preparation/cache, weighted graph construction, empty-support handling and timing/diagnostics.
- `models/tvcformer_siamese.py`: integrates Siamese graph builder while leaving official forecast architecture intact.
- `models/evaluation.py`, `analyze_graph.py`: embedding and graph metrics/visualization.
- `analyze_datasets.py`: train-split-only data distribution, scale and pairwise Pearson diagnostics.
- `benchmark.py`, `summarize_results.py`: paired/resumable E0/E1/E2 multi-dataset suite, status CSV, grouped mean/std and paired improvement percentages.
- `configs/common.yaml`, five dataset YAMLs and E0/E1/E2 overlays.
- `scripts/{ETTh1,ETTh2,ETTm1,ETTm2,Weather,run_all}.sh`: full suite launchers with argument forwarding and failure propagation.
- `tests/test_siamese_graph.py`: shared encoder, similarity, non-Pearson candidates, support symmetry, self-loops, GraphSAGE shapes, gradient paths, collapse diagnostics, context-only inputs, one-channel and non-finite edge cases.

The run outputs are isolated in `Siamese_TVC/logs`, `checkpoints`, `results`, and `analysis`. Existing smoke artifacts under `results/benchmark.csv` were not overwritten. The previous smoke metrics are historical and do not validate the latest normalized-CNN/Borda implementation.
